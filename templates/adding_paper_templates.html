Adding Paper Templates

01 / Getting started

Create your file

A paper / print template is a plain-text .ini file that defines paper size, card dimensions, positions, and printing options. A cutter template is a separate file opened in your cutter software. You only need the first to print.

  1. Open print/templates/ inside your Deckadence folder. For a packaged installation, this is beside the application executable; for a source checkout, it is inside the project folder. Create the folders if needed.
  2. Copy a similar existing .ini file, or paste the starter below into a plain-text editor.
  3. Save as a new file such as My A4 Cards.ini, using UTF-8 encoding. Make sure the filename ends in .ini, not .ini.txt. Put it directly in print/templates/; subfolders are not scanned for templates.
  4. Give it a unique Template_ID and a clear Display_Name. Keep the ID stable once you use it: saved settings and cutter associations refer to that ID.
  5. Reload the app page, open Print Settings, and select your template for the appropriate print flow. File changes are detected when the template registry is accessed.
Use a new ID for a new layout. Duplicate IDs in the same folder cause a load error. In a packaged installation, a runtime file with the same ID can override a bundled template; use that only when deliberately replacing it.
02 / Ready to customize

A4 · Nine cards · Hand cutting

This example centers nine 63 × 88 mm cards on an A4 portrait sheet, with 0.5 mm bleed on each edge. It enables Card Print / Chaos Draft and leaves cutter registration off. Copy the entire block into your new file.

[Template]
Schema_Version = 1
Template_ID = my-a4-nine-card
Display_Name = My A4 - 9 Cards
Description = Centered A4 cards with 0.5 mm bleed.
Enabled = True
Momir_Support = False
CardPrint_Support = True
FeaturedTemplate = False

[Metadata]
Printer = Any
Printer_Model = Any
Paper_Stock = Any
Paper_Stock_Type = Cardstock
Paper_Size = A4
Orientation = Vertical
Silhouette_Support = False
Tags = A4, Vertical, 3x3, Hand Cutting

[Page]
Width_mm = 210
Height_mm = 297

[Card]
Finished_Width_mm = 63
Finished_Height_mm = 88
Bleed_mm = 0.5
Rotation_Degrees = 0

[Layout]
Type = Grid
Columns = 3
Rows = 3
Horizontal_Spacing_mm = 1
Vertical_Spacing_mm = 1
Horizontal_Alignment = Center
Vertical_Alignment = Center
Fill_Order = Top_Left_Row_Major

[Rendering]
Add_Edge_Bleed_Border = True
Fill_Unused_Slots_With_White = True
Corner_Radius_mm = 3.25
Round_The_Corners = False
Uses_Fixed_Inner_Margin = True

[Duplex]
Back_Side_Slot_Order = Mirror_Horizontal

The required sections are [Template], [Page], [Card], and [Layout]. Preserve their spelling. Use schema version 1, numeric dimensions without units, and True / False for switches.

03 / Make it fit

Paper, bleed, and placement

All physical measurements are in millimeters. Page dimensions control the actual sheet; metadata labels only help you find the template. For US Letter portrait use 215.9 × 279.4 mm; swap width and height for landscape.

Common settings and what they change
SettingWhat to use it for
Support switchesEnabled = True makes the template available. CardPrint_Support and Momir_Support control the flows in which it appears. Enable Momir only for a layout you have tested in that flow.
Finished size & bleedFinished size is the cut card. Slot size includes bleed: finished size + twice Bleed_mm. Optional Slot_Width_mm and Slot_Height_mm override that calculation.
Spacing & stepsHorizontal_Spacing_mm / Vertical_Spacing_mm measure the gap between finished card edges. Steps default to finished width / height + spacing. Optional Horizontal_Step_mm / Vertical_Step_mm specify exact distances between slot origins.
Alignment & originsHorizontal alignment accepts Left, Center, Right; vertical accepts Bottom, Center, Top. Optional Start_X_mm / Start_Y_mm override alignment. The grid origin is its lower-left slot, measured from the page’s lower-left corner.
Order & rotationGrid fill order is Top_Left_Row_Major: left to right, then the next row down. Rotation accepts 0, 90, 180, or 270. For a rotated layout, check slot dimensions and steps explicitly; rotation does not swap the grid’s width and height settings.
RenderingUses_Fixed_Inner_Margin = True uses the template’s physical slot positions. Add_Edge_Bleed_Border extends edge pixels when source bleed is unavailable; Fill_Unused_Slots_With_White fills empty card positions. Corner_Radius_mm controls generated card shapes. Set Round_The_Corners = True to clip printed cards to their finished size with that corner radius, leaving the page visible outside the rounded corners. This also clips any bleed outside the finished card. It defaults to False, keeping existing print behavior.
Duplex mappingBack_Side_Slot_Order accepts Same, Mirror_Horizontal, Mirror_Vertical, or Reverse. Choose the mapping that matches your printing and sheet-flip workflow, then test front/back alignment.
Search labelsUse Printer, Printer_Model, Paper_Stock, Paper_Stock_Type, Paper_Size, Orientation, and comma-separated Tags to describe compatibility. They do not configure the printer driver.
Check the whole grid: width = slot width + (columns − 1) × horizontal step; height = slot height + (rows − 1) × vertical step. The example occupies 192 × 267 mm, leaving 9 mm left/right and 15 mm top/bottom. Keep every slot inside the printable area and clear of any registration marks.
Advanced: individually positioned cards

Use Type = Explicit in [Layout] for irregular placements, then add one numbered section per slot. Slots are assigned in numeric order. Each requires X_mm, Y_mm, Width_mm, and Height_mm; positions use the page’s lower-left origin. Width and height include bleed. Finished dimensions default to [Card], but slot rotation defaults to zero.

[Layout]
Type = Explicit

[Slot_1]
X_mm = 10
Y_mm = 15
Width_mm = 64
Height_mm = 89
Rotation_Degrees = 0

Keep the required Template, Page, and Card sections, and add [Slot_2], [Slot_3], and so on as needed.

04 / Before a full batch

Test your sheet

  1. Select the template in Print Settings for Card Print / Chaos Draft or Momir, according to its support switches. Clear selector filters if necessary.
  2. Preview or export a small print job. Check the page size, card count, orientation, margins, and any registration background.
  3. Print one sheet on inexpensive paper at actual size / 100%, with scaling or “fit to page” disabled. Match the driver’s paper size to the template.
  4. Measure finished card dimensions and spacing with a ruler. For duplex, print identifiable fronts and backs and check their alignment after your normal sheet flip.
  5. Only after a successful test, use the intended stock and, if applicable, test the cutter on a single sheet.
Optional / Cutting machines

Add Silhouette or other cutter profiles

Export the paper’s cut paths to your cutter software, then bring its registration artwork back to Deckadence. Configure blade depth, force, speed, and passes in your cutter software for your machine and material.

Create a template in your cutter software

  1. Open Settings → Card Cutting Machine Templates → Cutter Template Setup and select your existing paper layout.
  2. Download the ZIP and open its SVG, PDF, or EPS cut paths in your cutter software. Keep the full page size, actual scale, and path positions. The ZIP also includes instructions and JSON geometry for programmers.
  3. Create the cutting template in that software, then export a full-page file containing only its registration marks.
  4. Return to Deckadence and choose Upload Registration Marks for the same paper layout. Enter a friendly name, cutter brand, and model, then browse for PNG, SVG, PDF, JPG, JPEG, or WebP artwork. The format is detected automatically.
  5. In Print / Export, enable Cutter Registration Marks and choose your cutter template from Select Cutter. Deckadence remembers the selection for this paper. Print a test at 100% scale before cutting.

Each paper layout can have multiple cutter templates. Uploading registration marks adds a cutter choice to the existing paper; it does not create or change a paper layout.

To manage saved files, open Settings → Card Cutting Machine Templates. Choose Registration Marks to download or remove an uploaded registration file, or Cutting Templates for your cutting-machine files. Removal asks for confirmation and keeps the paper layout.

Manual setup and existing Silhouette layouts

Start from a working Silhouette paper template with matching paper size and geometry. In [Metadata], set Silhouette_Support = True and optionally Silhouette_Model = Any or your model. Add a registration background:

[Silhouette]
Registration_Background = assets/my-registration-marks.png

Place the image in print/templates/assets/. Its path is relative to the INI file. Match the background’s full-page proportions, mark positions, card locations, and orientation to your cutter document. Keep artwork outside the cutter’s registration exclusion areas. Setting the support flag alone does not create registration marks or a matching cut file.

Upload and link the cutter file

  1. Open Card Cutting Machine Templates from the application menu or the Card Print screen.
  2. Choose Add Cutting Machine Template and select a .studio3, .svg, .dxf, or .fcm file.
  3. Enter Cutting Machine Brand and Template Name, plus an optional description. Include useful model, paper, orientation, and material notes.
  4. Choose the exact Linked Print Template, then select Upload Template. Any enabled Card Print template can be linked; Silhouette support is not required for other brands.
  5. Filter the library by paper / print template and brand. Download the file, open it in compatible cutter software, and verify its dimensions and cut paths against your printed test sheet.

For other brands, use a format your software can import and its own registration workflow. An accepted upload extension does not guarantee that a particular machine or software edition can use the file.

Reference / Quick fixes

Troubleshooting

My paper template is missing
Check the folder and .ini extension, Enabled, and the relevant support switch. Reload the page and clear template filters. Look in Reminders for a Print Template Load Error, which includes the filename and parsing problem.
The template fails to load
Check required sections, schema version 1, a unique ID, positive page/card dimensions and row/column counts, and valid values. Use decimal points for numbers; keep units out of numeric fields.
Cards overlap or run off the page
Recheck slot size, bleed, steps, and origins together. Changing the paper label does not resize the page. A file that loads successfully still needs a physical layout check.
The whole sheet prints too small
Check printer scaling and paper size first. Changing card dimensions to compensate for “fit to page” can make the template incorrect on other printers.
Cut lines or card backs are offset
Confirm the exact linked print layout, orientation, registration background, duplex mapping, and printer scaling. Calibrate alignment in the appropriate printer or cutter workflow, then repeat a single-sheet test.
The print layout is missing from the cutter upload list
It must load successfully with Enabled = True and CardPrint_Support = True. Reload the page and reopen the library after saving the INI file.
