Export custom sets, saved decks, packs, campaigns, players, history, alternate and isolated artwork, upscaled images, deck art, custom icons and card backs, modified print and cutting templates, and settings. Plugins, AI models, base Scryfall images, application files, and the full database are excluded.

Large backups are saved on disk before downloading. Choose a drive with enough free space. Backups are kept separately from Export cleanup. Other application requests pause while a job runs.

Import user content

Import adds content to your existing database. Decks, packs, campaigns, players, and isolation scopes receive new identifiers; conflicting custom set codes and template names are renamed. Existing content is preserved. Imported settings and custom pack artwork overrides are applied. No restart is required.

For 10–100 GB backups, use a local ZIP path to avoid uploading another copy. Import needs free space for extracted custom assets and temporary record processing.
