Adapter boundaries

Download reference Jinja field macros. The examples centralize label association and row-selection naming. A render check verified unique IDs, associated labels, selected options and escaped text. Caller-owned IDs must remain unique across the whole page.

patterns.js contains reference classes; demo.js and workflows.js supply page-specific wiring. Neither script should replace the application's existing UI layer wholesale.

  • DirtyFormController: the demonstration restores simple, uniquely named text/select/checkbox fields. Repeated names, radio groups, multi-selects, files and rich editors need a typed snapshot adapter. FormData excludes disabled controls; decide intentionally whether such values belong in the saved baseline.
  • CollectionController: sample deck filtering is local and deck-specific. Production reuse belongs in shared toolbar markup and selection behavior, while page adapters retain their existing server queries and result rendering.
  • DialogController: native dialog demonstrates focus isolation. Existing custom overlays require migration or a compatibility adapter. Test nested overlays and asynchronous close races before widespread adoption.
  • JobController: demo text and timing are PDF-specific. Keep the existing production export controller; use the sample to align visible status, error recovery and focus behavior.
  • NumericEntryController: the sample accepts 0–99. Production limits and validation messages must follow the game's actual rules and server validation.

Verification scope

The demonstration primary-button blue was adjusted from #3a7afe to #2563eb: calculated white-text contrast improves from 3.89:1 to 5.17:1. This changes only the review stylesheet. Sample muted text, links and body text measured 9.01:1, 9.28:1 and 13.75:1 against their specified backgrounds; this is not a complete audit of production colors or interactive states.

The review uses a copied database and read-only HTTP access. It does not establish that real saves, deletions, imports, backups, remote deck providers, physical printers, or dual-faced image requests work end to end. Those paths need targeted integration checks after the shared components are adopted.

Keep the existing backup changes separate from this UX work. Review the active backup flow against the job contract when those changes stabilize. The idle fixture does not simulate an in-flight backup.

Phone inspection covers representative layouts, not every device. The browser viewport override sometimes reports 355 px after requesting 390 px; retain the measured width with any screenshot evidence. Keyboard testing does not substitute for a screen-reader pass.
