Deckadence release UX review

Open index.html in a modern desktop browser. Keep this directory together:
the report, demonstrations, scripts and styles use relative file paths.
No installation or internet connection is needed for the sample demonstrations.
Sample edits reset when the page reloads. Save and output operations are simulated.

READ
  index.html       Prioritized findings, all-page coverage, exact template repair
  adoption.html    Shared-component contracts and release acceptance checks

TRY
  demos.html       Filters, selection, confirmation, save/retry, output, Momir input
  workflows.html  Shorter home and cards-first set editor

INSPECT
  chaos-pack-template-fix.patch   Proposed minimal production repair; not applied
  field_macros.html              Reference Jinja macros; open in a text editor
  patterns.js                   Reference controllers; see adoption limitations
  template-check.json           Original template validation and route inventory
  fixture-check.json            Isolated rendering checks
  progress.json                 Audit checkpoints and remaining limitations

OPTIONAL LIVE REVIEW SERVER
From D:\MTG\Deckadence in PowerShell:

    python tools\ux_review_server.py

Then open http://127.0.0.1:5011/ux-review/index.html
If the server is already running, use that URL without starting another instance.
The server reads production templates but uses a copied runtime/database under
Export\ux-review\runtime. It blocks HTTP mutations and outbound Python requests.
The review does not modify production settings, decks or templates.

The report lists untested integration paths explicitly. It is a UX audit with
working references, not an installed redesign or a complete release certification.
