
## Development artifacts
Use only `.dev_prompts/ai_work/` for AI development scripts, working documents, tests, mockups, screenshots, review servers, fixtures, and temporary outputs. The rest of `.dev_prompts/` is reserved for the user's files; do not add AI artifacts there. Do not create other development folders or put development artifacts in production asset directories. Keep these artifacts ignored by Git. Production code and required release logic belong in their existing production files.
